# makefun-ai-joke-03

[![make.fun · ai-joke-03](https://make.fun/c/ai-joke-03/badge)](https://make.fun/c/ai-joke-03)

Entry for [make.fun](https://make.fun) competition **ai-joke-03 — Make the AI judge laugh**.

The program writes one joke about AI coding agents to `/output/entry.txt`:
one line, deterministic, standard library only, no network.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

## Joke

> My coding agent wrote 500 lines in ten seconds. I've spent an hour reviewing them. It just asked if I want 500 more.
